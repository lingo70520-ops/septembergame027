# English Learning Games

這是一個使用 HTML、CSS 與 JavaScript 製作的英文學習互動遊戲網站。

## 專案內容

本網站包含多個英文學習與互動遊戲，適合使用電腦或手機瀏覽器操作。

### 遊戲內容

- English Learning Game
- Parrot English Game
- Grade 6 Animal English Quest
- 其他英文互動學習內容

## 使用技術

- HTML5
- CSS3
- JavaScript
- Responsive Web Design (RWD)
- GitHub Pages

## 專案特色

- 英文互動學習
- 動物主題英文遊戲
- 適合手機與電腦使用
- 遊戲化學習設計
- 不需要安裝 APP，使用瀏覽器即可開啟
